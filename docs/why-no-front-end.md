# Why the base has no front end

A coordinator can review role requirements, assessments, expiry and training actions by asking the coding agent and reading generated reports. Those are records and recurring reviews. The database is the product; the agent is the door.

AG5 supplies interactive matrices, mobile workflows, integrations, notification workflows and enterprise controls. This base supplies local commands and static HTML snapshots. A snapshot is dated when generated. It does not update in an open browser. There is no mobile capture, offline synchronisation, drag and drop, automatic reminder service, self-assessment portal or identity provider.

The operator runs refresh commands and a supervisor evaluates evidence. An actor name in the audit history is supplied by the operator; it is not authenticated identity. Shared deployment requires proper access control and identity integration. Enterprise DNA can build shared interfaces, identity controls and integrations into your version. None is implied by this free base.
